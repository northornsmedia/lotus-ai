# Contributing to Lotus AI

Thank you for your interest in contributing to Lotus AI and expanding the sovereign frontier intelligence ecosystem!

## 🚀 How to Contribute

1. **Star the Repository** to support our open-source release!
2. **Submit Integration Examples**: We welcome PRs adding examples for popular agent frameworks (LangChain, LlamaIndex, CrewAI, AutoGen, Cursor, Continue.dev, LiteLLM).
3. **Report Edge Cases & Evals**: If you find challenging STEM or reasoning problems where Lotus 0.1 Max can be improved, please open an issue with the prompt.
4. **Improve Documentation**: Enhancements to guides, quickstarts, and client SDKs are always welcome.

## 🛠️ Development Setup

```bash
git clone https://github.com/northornsmedia/lotus-ai.git
cd lotus-ai
npm install
npm run dev
```

## 📜 Code of Conduct

Lotus Labs is committed to providing a friendly, safe, and welcoming environment for all developers and researchers.
